CineLive: FongMi 原版功能 + 自动源维护

本次交付：0.1.5-stream-dev（versionCode 6）
- 15 个点播、6 个直播订阅。新增 Free-TV、范明明和 Guovin；新增候选均有实际音视频包抽测记录，未通过的 ssili126 / wwb521 未加入。
- 抽测不代表全部频道或家庭网络可播；直播设备本机直连首帧渲染与持续进度检测通过后，才保存为可用/备用线路。
- 非计费网络后台更新候选清单；最近观看优先，每轮轮询 10 个频道，最多为每频道保存两条当前网络近期通过的线路。
- 打开频道优先使用本机当前网络 30 分钟内验证结果；没有记录时先检查，未通过或超时仍交给原版播放器尝试原始线路，当前线路播放失败时失效记录立即剔除并尝试同频道备用；失败线路冷却 10 分钟。
- 保留所有原始线路和手动切换；各线路请求头独立，账号头不会移交给另一发布者。回看及特殊插件直播继续原版链路。
- 家庭私用包内置 VLESS / Reality，只为 allowlist 内的内置配置更新提供直连失败后的备选通道。没有 VPN 服务、监听端口或系统代理；播放、搜索、插件、用户自定义 URL 不使用家庭线路。
- 429 / Retry-After / 404 不切代理重试。维护错误保留缓存。凭据仅存在私用 APK 的外部注入资源，不在此源码包中。
- 修正网络超时被当作取消而漏回调的问题；原版历史/手动换源的加载阶段最多 45 秒结束提示。内置目录预检另有 45 秒上限；直播前台预检最多 12 秒，播放缓冲超时 20 秒进入故障处理。
- 内置源/源维护统一深色背景、青绿色焦点、可换行按钮，两个标签增加间距；长内容滚动并避让系统栏。
- 同包名、同签名覆盖旧 CineLive，无需卸载。手机推荐 ARM64，当贝 B3 Pro 可先用电视 ARM32 包。

0.1.4 修复
- 订阅缓存读取不等待网络；每个订阅独立串行写入，慢源不再占住所有源的缓存锁，等待同源更新可取消。
- 直播目录刷新与本机预检分别调度；播放器服务退出后恢复后台预检，周期缩短至 15 分钟检查机会，单次后台检查有时间上限。
- 已验证线路按明确 TVG ID 隔离；没有 ID 的普通同名频道仅在自身线路集合内复用，避免“新闻”等同名台串线。旧版按名字缓存不再使用。
- 不再只测试前 3 条线路；保留检测游标，预检超时后尝试原始线路，下次预检继续后续候选。0.1.5 改为 12 秒前台预检总期限，不能保证一次遍历大量线路。
- 回看和刷新会取消旧的直播预检；迟到结果不得覆盖回看选择，回看解析失败也不会自动切回直播。
- 电视线路预检要求解码首帧及至少 1.5 秒持续进度；明确标为广播/电台/radio/FM 的频道允许纯音频。播放列表可读、READY、少量缓冲均不足以成为备用。
- 预检基于 ExoPlayer；仅 MPV 支持的特殊编码可能不能成为自动备用，仍可手动使用原始线路。模拟测试不等于真实设备解码验证。

自动维护
- 原版设置/电视首页新增“源维护”入口，可关闭自动检查。
- Android JobScheduler 大约每 15 分钟获得检查机会；成功订阅的检查间隔为 6 小时，系统可能推迟后台任务。
- 对当前点播配置、直播配置、已选直播列表进行结构验证及持久缓存。
- 点播/直播配置各支持最多 5 个同一发布者的备用地址。主地址失败、空列表、异常缩水时依次尝试。
- 主地址在下一轮检查时重新优先尝试；所有地址失败时保留上次成功缓存，并遵守错误退避及 Retry-After。
- 订阅更新只保存配置，下次加载生效；后台不加载插件、不切台。播放服务存在时暂停后台解码预检，闲置时另开静音短时解码，不替换正在观看的频道。
- 带账号请求头的直播列表只刷新原 URL，不将这些请求头转发给备用域名。
- 本版本不自动搜索任意网站寻找新发布地址，不宣称订阅结构通过就代表每部影片/每个频道能播。
- 原有源插件自己的网盘授权界面照常可用；未加入未经核实的共享会员。

构建
JDK 21、Python 3.10、Android SDK 37.0、Build Tools 36.0.0，以及固定播放器源码：
  git clone --branch release-1.11.0-fongmi https://github.com/FongMi/media.git /path/to/media
  git -C /path/to/media checkout 3c2cbe8ac742c2fe15eff52f03eeb3b1b648848d
在本工程目录运行：
  python tools/check_native.py
  python tools/build_android.py --media-dir /path/to/media --sdk-dir /path/to/android-sdk --python /path/to/python3.10
网络需要国内 Maven 镜像时加 --china-mirror。
输出 app/build/outputs/apk/{mobile,leanback}/debug，各有 ARM32/ARM64 包。
本版源码含维护核心 AAR，可直接构建无家庭线路版本；重建核心见 maintenance-core/BUILD_AND_SCOPE.txt。
家庭私用包另加 --maintenance-private-assets-dir /outside/source/private-assets，目录内只有 family-maintenance.txt。不要把该目录加入交接源码或公开分享。

交付边界
- 当前为开发调试包，不能作为未经真机验收的家庭正式版。
- 未接入正式 APK 更新清单；更新入口保留，未配置时会说明服务尚未启用。
- 原版包名和旧 CineShelf 包均不被覆盖，也不会自动迁移原账号与订阅。新装后可从内置目录选择，也可以在原设置页导入订阅。
- 尚未在当贝 B3 Pro 或用户手机上安装验收；未执行用户账号操作。

界面回归：
  ./gradlew :app:testMobileDebugUnitTest --tests "*SourceEntryTest"
需要与构建相同的 SDK、media、Python 和镜像参数。Robolectric SDK 28/35/36 验证真实 Activity/Fragment/输入对话框，ARM 原生插件加载器在 JVM 测试中替身处理，不包含插件执行或真实视频播放。界面、超时与直播选择策略回归及 73 项基础检查见本版 verification.json；不能替代当贝 B3 Pro 真机验收。

0.1.5 深入稳定性修复
- 修复先收到频道、后绑定播放服务导致的空指针；保存用户最后选择，等待绑定后播放。退出页面、失去绑定或过期解析回调不得继续使用旧播放器。
- 播放服务释放后才恢复后台解码，避免预检争抢解码器。网络改变后旧验证记录不再复用。优先检查当前列表和近期观看频道。
- 直播前台预检上限 12 秒；失败不代表永久不可播，原版播放器仍可尝试原始线路，但这些线路不会被标成已验证备用。自动尝试有上限，耗尽显示错误。
- 点播解析空地址、播放错误与持续缓冲超时进入同集换线；跨站点核对标题、年份以及双方均提供的导演/类型。同名翻拍、缺少年份和不明确集数不自动播放。
- 自动跨站最多 8 次、每集自动搜索一轮；保留各站陆续返回的候选并去重，手动重试可重置额度。换线保留播放进度。
- 修复旧播放超时回调停止新线路的问题；迟到的旧解析结果不能覆盖当前请求。
- 源维护滚动区域统一避让系统栏，错误详情增加一键复制；维护刷新有总超时。界面区分配置检查与媒体播放验证。
- 当前为本机定时检测，没有部署云端全量点播试播服务。没有任何来源可承诺永久可用。
- 新增真实本地 HTTP 故障注入测试（主配置异常→备用→全失败保留缓存），真实控制器测试仅替代解码器结果。
- 6 个公开直播列表各有 2 路 FFmpeg 实际视频解码通过，共 12 路；仅代表构建网络抽测，不代表 Android 硬件或家庭网络。
详细检查结论、未完成项、验收步骤见 STABILITY_AUDIT.txt 与本版 verification.json。

公开直播解码抽测复跑：安装 Python json5 与 ffmpeg/ffprobe，工程根目录运行 PYTHONPATH=. python tools/probe_live_media.py。按所在环境配置 HTTPS_PROXY；报告输出 reports/。此工具只做公开地址只读检查，不使用家庭节点。
