CineLive 0.1.5-stream-dev 深层检查与交接（2026-10-15）

结论：自动维护和自动故障切换有实际执行链路，本轮补上了影响它们的关键缺陷；还不能认定为已经完成家庭真机验收、永久免维护。

1. 直播崩溃
证据：用户截图 PlaybackActivity.player → LiveActivity.stopPlayer → stopPlaybackForRefresh → LivePlaybackController.prepareLive。播放服务未绑定即使用 player。原有代码可复现，修复后由控制器延后播放并保留最后选择；服务超时提示返回重试。退出后迟到绑定/解析/预检不得重新播放。两个端共用控制器，手机和电视入口均作保护。

2. 订阅层自动维护：已实现
Android JobScheduler 请求 15 分钟检查机会，成功订阅默认 6 小时间隔，失败退避。检查点播/直播配置以及当前直接直播清单；主地址失败依次尝试已配置备用，均失败保留最近成功缓存。格式检查、空列表与异常缩水保护不等于影片/频道可播。
真实 localhost HTTP 测试：主地址返回 HTML，转备用有效 JSON 并以备用地址解析相对 plugin 路径；随后全部失败仍返回已缓存配置。测试没有执行远端插件。
不是全网找源：内置目录 15 点播、6 直播，随 APK 发布；没有部署追踪发布者新域名的远程目录服务。多数条目没有公开可靠镜像，备用数 0 必须如实显示，不能伪造。

3. 直播媒体层：已实现，但受设备和网络条件限制
普通 HTTP(S) 频道在设备当前非计费网络闲置时后台静音预检，优先当前列表/常看频道；视频需解码首帧及至少 1.5 秒连续进度。明确命名的广播频道允许纯音频。结果仅当前网络 30 分钟有效，失败冷却 10 分钟。
播放服务存在时停止后台解码，防止资源竞争。开台优先近期通过结果，无记录执行有界预检；失败/超时仍可交给原版播放器尝试原始线路，不把未验证线路作为健康备用。
直播真实播放失败/持续缓冲超时后剔除失效记录，自动尝试同一频道的备用，最多尝试 8 条，耗尽明确提示。跨清单依明确 TVG ID 匹配；无 ID 普通同名台不跨清单自动合并。原有自动换线设置关闭时尊重用户设置。
回看与特殊插件/协议保留原版逻辑，不宣称全部经过预检；仅 MPV 支持的媒体可能通过原版播放但无法进入 ExoPlayer 验证备用。
没有任何检测可保证开台后永久不失效，也不能承诺每个频道都有同台可用备用。

4. 点播媒体层：播放时已增强，后台全量试播未实现
解析失败、空播放地址、播放错误、持续缓冲超时进入失败处理。允许切源的站点先尝试同一集的其他线路；跨站搜索保守核对片名、年份、双方提供的导演/类型与集数，最多切换 8 个站点候选。未知年份或不能确认同集时停止自动播放，保留手动选择。
同集换线保留播放位置；自动搜索每集一轮、失败不会无穷重搜；多个站点陆续返回的候选合并去重。手动重试可再次发起。
没有云端服务器全量检查全部点播插件和影片，没有对登录、付费、验证码源绕过认证。测试覆盖控制器行为，不等于所有远程插件都已验证可播。

5. 网络范围
私用 APK 的家庭线路仅用于许可名单中内置配置更新的直连失败备用；播放、搜索、插件下载和自定义 URL 继续普通网络。配置可获取不代表家庭网络可以直连其实际媒体地址。
本轮验证仅涵盖线路作用范围与私有配置结构，未完成家庭节点握手、用户手机和当贝 B3 Pro 实机验证。

6. UI 与诊断
修复滚动后系统栏文字重叠；维护页区分配置通过和媒体通过；刷新有超时，不永久转圈。崩溃详情增加复制按钮且文字可选择。

7. 验证方法与交付限制
Android Robolectric 覆盖 SDK 28/35/36 的真实 Activity/Fragment、控制器、延迟绑定、断连、退出、旧请求、换线和 UI 安全区域。ARM 插件加载/媒体解码在 JVM 中使用替身，不能替代硬件。
73 项独立基础/并发/媒体证据判定检查、6 项 Go 核心检查；本版最终 Android 测试数量见 verification.json（失败必须为 0）。
6 个公开直播清单各 2 路 FFmpeg 软件视频解码通过（总 12），包含网络包/视频帧证据。通过会话网络代理在构建环境执行，不代表家庭无 VPN 网络。失败样本也保留在报告。
原版完整点播/直播功能保留；未加入自定义 115/磁力。正式 APK 更新清单与新增授权配对扩展未部署/未迁入，见功能迁移清单。

8. 家庭验收步骤（未执行）
覆盖安装后设置中确认 0.1.5-stream-dev；手机 ARM64，盒子先用电视 ARM32。
家庭网络关闭系统 VPN，分别选点播/直播内置订阅，核对加载结果和维护通道。
反复进入/退出直播、连续换台、切前后台、换 Wi-Fi，确认无崩溃/误播。测一条失效线路和同频道有效备用，确认自动恢复而非循环。
点播同一集换线、跨站来源核对与播放位置；找不到同片同集时应停止并提示。
遇错误可一键复制详情。不能仅凭“配置检查通过”判定播放验收成功。
